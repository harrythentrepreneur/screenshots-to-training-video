How it works

Five stages, from a brief to a finished video.

The first phase writes the script. The second turns it into video. Three stages call paid APIs, and two run on your own machine.

01

Vision

Describes what is on each screenshot.

GPT-4oOpenAI key
02

Script

Writes intro, steps and outro, and tags each line with [SHOW: n].

GeminiGoogle key
03

Presenter

An avatar reads the script out loud.

HeyGenHeyGen key
04

Timing

Finds the second each [SHOW: n] line is spoken.

Whisperlocal
05

Compositing

Cuts screenshots in on cue and puts the presenter in a circle.

Try it without keys

The compositing stage runs on its own.

The repo ships a small example: four screens from a made-up app called Acme Dashboard, a hand-written script and cue times, a silent placeholder presenter and a circle mask. One command runs the real VideoProcessor on them.

# needs only ffmpeg on your PATH
$ python examples/run_compositing.py
# -> data/output/processed_video.mp4
#    1920 x 1080 · 14 s · 4 cues

# examples/acme-dashboard/TIMING.txt
[SHOW: 1] Welcome to Acme Dashboard…
[SHOW: 2] Open Projects from the sidebar…
[SHOW: 3] Give the project a name…
[SHOW: 4] Invite a teammate by email…
Screens are scaled to 85% and centred on a white 1920 × 1080 canvas.
Each screen shows from its cue until the next cue.
The presenter is cropped square, masked to a circle and placed bottom right.
The API

One endpoint runs the whole pipeline.

Quick start

Install it and add your keys.

$ git clone https://github.com/harrythentrepreneur/screenshots-to-training-video.git
$ cd screenshots-to-training-video
$ python -m venv .venv && source .venv/bin/activate
$ pip install -r requirements.txt
$ pip install openai-whisper
$ cp .env.example .env   # add your keys
$ uvicorn src.api.main:app --reload

Keys

OPENAI_API_KEYStage 1, vision
GOOGLE_API_KEYStage 2, script
HEYGEN_API_KEYStage 3, presenter
HEYGEN_AVATAR_ID
HEYGEN_VOICE_ID		Which avatar and voice

Inputs go in data/input/: context.txt (title, goal, detail) and screenshots/1.png, 2.png and so on.
